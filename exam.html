ЛЕКСИКА
1 Запишите иероглифы данных слов в соответствии с переводом.
1) Велосипед____
2) Вкусный____
3) Лапша____
4) Танцевать____
5) Ежедневный, повседневный; часто, постоянно____
6) Килограмм____
7) Дорога____
8) Компания____
9) Медленный____
10) Ходить____
✅ Правильные ответы:
1) 自行车 · 2) 好吃 · 3) 面条 · 4) 跳舞 · 5) 经常 · 6) 公斤 · 7) 路 · 8) 公司 · 9) 慢 · 10) 走
Не забудьте: 慢 и 快 — это пара «медленный/быстрый». 走 — именно пешком, а 去 — «идти куда-то».
Можно ещё проверить слова из этой же серии: 快 kuài — быстрый, 每天 měitiān — каждый день. Они встречаются в ДЗ.
慢: сердце (忄) + сеть с солнцем — тянет медленно. 快: сердце (忄) + бегущий человек — быстро.
2 Определите, верно ли переведены слова.
1.告诉 gàosu — сказать (думать)
✅ 不对 — 告诉 = «сказать, сообщить», а «думать» = 觉得 / 想.
Запомните: 告诉 — обязательно кому-то что-то сказать. Без человека нельзя.
Можно ещё проверить: 说 (shuō) — говорить; 说 + 话 (huà) — разговаривать.
2.事情 shìqing — событие, дело (событие)
✅ 对 — 事情 = «дело, событие, вопрос».
Слово нейтральное. Часто встречается: 我有事情 — у меня есть дело.
Можно ещё проверить: 事 (shì) — сам корень «дело», часто в коллокациях 有事 / 没事.
3.错 cuò — ошибочно, неправильно (ошибочно)
✅ 对 — 错 = «ошибка, неправильно».
Пара: 对 — правильно, 错 — неправильно.
Можно ещё проверить: 不对 (bú duì) — неверно; 没错 (méi cuò) — верно, точно.
4.上班 shàngbān — идти на работу (группа)
✅ 不对 — 上班 = «ходить на работу». «Группа» = 班 или 小组.
上班 ≠ «группа». Это действие. Группа — 班 (bān), но отдельно почти не используется.
Можно ещё проверить: 下班 (xiàbān) — уходить с работы; 上班族 — офисные работники.
5.手机 shǒujī — мобильный телефон (ноутбук)
✅ 不对 — 手机 = «мобильный телефон» (ручной + механизм). «Ноутбук» = 笔记本电脑 или 电脑.
Логика: 手 — рука, 机 — механизм → «ручной механизм» = мобильный.
Можно ещё проверить: 电脑 (diànnǎo) — компьютер; 手机号码 (shǒujī hàomǎ) — номер мобильного.
3 Заполните пропуски подходящими по смыслу словами.
Варианты: A 题 · B 告诉 · C 等 · D 教室 · E 手机
1.女：今天下午你们在哪个（ ）上汉语课？
男：还是 407。
✅ D · 教室
今天下午你们在哪个 教室 上汉语课？ — «В какой аудитории у вас сегодня после обеда урок китайского?»
407 — типичный номер аудитории. Значит, речь именно про место.
Можно ещё проверить: 教室 (jiàoshì) — аудитория; 房间 (fángjiān) — комната.
2.女：今天是你的生日，生日快乐！
男：谢谢，是谁（ ）你的？
✅ B · 告诉
谢谢，是谁 告诉 你的？ — «Спасибо, а кто тебе сказал?»
告诉 = «сказать, сообщить» — именно в контексте передачи информации.
Можно ещё проверить: 说 (shuō) — говорить; 问 (wèn) — спрашивать.
3.女：这个（ ）还有什么颜色的？
男：还有红色和黑色的。
✅ E · 手机
这个 手机 还有什么颜色的？ — «А какие ещё цвета есть у этого телефона?»
Цвета упоминаются — значит, речь о конкретном предмете в магазине.
Можно ещё проверить: 颜色 (yánsè) — цвет; 红色 (hóngsè) — красный.
4.我要睡觉了，那些（ ）明天再做吧。
✅ A · 题
我要睡觉了，那些 题 明天再做吧。 — «Я спать, те задачи — завтра».
题 = «задача, вопрос» — типичное домашнее задание.
Можно ещё проверить: 做题 (zuò tí) — решать задачи; 问题 (wèntí) — вопрос.
5.快点儿，大家都在（ ）你吃饭呢。
✅ C · 等
快点儿，大家都在 等 你吃饭呢。 — «Быстрее, все ждут тебя, чтобы поесть».
等 + 你 = «ждать тебя». Конструкция 等你.
Можно ещё проверить: 等一下 (děng yíxià) — подожди минутку; 稍等 (shāo děng) — подождите немного.
ГРАММАТИКА
4 Введите правильный вариант ответа.
这____商店的衣服____都很漂亮。
✅ 3) 个, 件
这 个 商店的衣服 件 都很漂亮 — «Одежда в этом магазине вся красивая».
个 — универсальное счётное, 件 — для одежды и дел.
Можно ещё проверить: 一件衣服 / 一个问题 / 一个商店.
因为她哥哥帮助我，____我送他礼物。
✅ 2) 所以
因为她哥哥帮助我，所以 我送他礼物。 — «Поскольку её брат мне помог, я дарю ему подарок».
因为 + причина, 所以 + следствие. Пара.
Можно ещё проверить: 因为...所以 — классическая связка; можно опустить 因为 или 所以, но не оба.
我吃了饭，____去你那里。
✅ 1) 就
我吃了饭，就 去你那里。 — «Я поем и сразу пойду к тебе».
就 после действия = «сразу после этого».
Можно ещё проверить: 回家就开始做作业 — «как только приду домой, сразу начну делать ДЗ».
学校____机场非常远。
✅ 2) 离
学校 离 机场非常远。 — «Школа очень далеко от аэропорта».
A + 离 + B + 远 / 近 — конструкция расстояния.
Можно ещё проверить: 我家离公司很近 — мой дом близко к компании.
别人都走了，为什么你____在这里？
✅ 1) 还
别人都走了，为什么你 还 在这里？ — «Все уже ушли, почему ты всё ещё здесь?»
还 здесь = «всё ещё» — продолжение состояния.
Можно ещё проверить: 还没 — ещё не; 还是 — или.
你明天____给我打电话吧。
✅ 2) 再
你明天 再 给我打电话吧。 — «Позвони мне завтра ещё раз».
再 = «ещё раз, снова» — когда-то в будущем.
Можно ещё проверить: 再读一下 — прочитай ещё раз.
商店的左边____是学校。
✅ 2) 有
商店的左边 有 学校。 — «Слева от магазина — школа».
有 = «имеется, находится» — классическое для описания местоположения.
Можно ещё проверить: 商店的右边有银行 — справа от магазина банк.
他不____我晚上给他打电话。
✅ 1) 让
他不 让 我晚上给他打电话。 — «Он не разрешает мне звонить ему вечером».
让 = «позволять / заставлять». 请 = «попросить вежливо». 叫 = «звать».
Можно ещё проверить: 妈妈不让我晚睡 — мама не разрешает мне поздно ложиться.
你看见王老师，____他到我这来一下。
✅ 1) 让
你看见王老师，让 他到我这来一下。 — «Увидишь учителя Вана — попроси его зайти ко мне».
让 + человек + действие — «пусть он сделает».
Можно ещё проверить: 让他等一下 — пусть он подождёт.
我____去年开始学习汉语。
✅ 1) 从
我 从 去年开始学习汉语。 — «Я начал учить китайский с прошлого года».
从 + время — «с какого-то времени».
Можно ещё проверить: 从早上八点到晚上六点 — с 8 утра до 6 вечера.
5 Впишите подходящий комплемент результата.
老师说的话我都听____了。 (懂)
✅ 懂 → 老师说的话我都听懂了。
听 + 懂 = «услышать и понять» — результатив.
Можно ещё проверить: 看懂 (kàn dǒng) — понять читая.
我妈妈看____你的女朋友了。 (见)
✅ 见 → 我妈妈看见你的女朋友了。
看 + 见 = «увидеть». 看 — процесс, 看见 — результат.
Можно ещё проверить: 听 + 见 = услышать.
我没做____了考试题。 (完)
✅ 完 → 我没做完考试题。
做 + 完 = «доделать до конца». Здесь с 没 — отрицание.
Можно ещё проверить: 吃完 (chī wán) — доесть; 写完 (xiě wán) — дописать.
你妈妈做____中国菜了。 (好)
✅ 好 → 你妈妈做好中国菜了。
做 + 好 = «сделать хорошо / закончить». Оттенок «успешно завершено».
Можно ещё проверить: 准备好了 — уже готов.
明天的汉语课你都准备____了吗？ (好)
✅ 好 → 明天的汉语课你都准备好了吗？
准备 + 好 = «подготовить полностью». Классическая коллокация.
Можно ещё проверить: 准备好 (zhǔnbèi hǎo) — быть готовым.
6 Составьте предложения из данных слов.
1. 第 · 请 · 现在 · 一个 · 回答 · 问题 · 你 。
✅ 现在请你回答第一个问题。
Порядок: время → подл. → гл. → объект. 第一个 = «первый».
2. 你 · 的 · 怎么 · 是 · 你的 · 认识 · 和 · 男朋友？
✅ 你和你的男朋友是怎么认识的？
是...的 — конструкция выделения способа. 怎么 + 认识 = «как познакомились».
3. 什么时候 · 吗 · 你知道 · 学校 · 今天 · 来 · 她？
✅ 你知道她今天什么时候来学校吗？
你知道…吗 — «Ты знаешь…?». Внутри — вопросительное слово 什么时候.
4. 中国 · 这儿 · 有 · 离 · 一个 · 饭馆 · 不远 。
✅ 离这儿不远有一个中国饭馆。
离这儿不远 — «недалеко отсюда». Классическая конструкция.
5. 我 · 打篮球 · 八岁 · 的时候 · 第 · 是 · 一次 · 在 。
✅ 我第一次打篮球是在八岁的时候。
是...的 — выделение обстоятельства времени. 第一次 = «в первый раз».
ЧТЕНИЕ
7 Прочитайте информацию и определите, верны ли утверждения под ★.
不要在公共汽车上看书、看报纸，因为那样对眼睛不好。
★坐公共汽车对眼睛不好。
✅ 不对
В тексте: «на автобусе читать вредно для глаз», а не «автобус вреден сам по себе».
Ловушка: убрали ключевое действие 看书/看报纸 и оставили «автобус» — это подмена.
从学校到机场，坐车要一小时，我们十点的飞机，八点从学校走可以吗？
★他们坐八点的飞机。
✅ 不对
У них самолёт в десять, а в восемь они выходят из школы.
Числа 10:00 и 8:00 легко перепутать — читаем внимательно.
姐姐，第一题我不会做，你做完饭能帮我看看吗？
★姐姐正在房间里学习。
✅ 不对
Сестра в этот момент готовит (做完饭), а не учится.
做饭 ≠ 学习. Не путать.
刘小姐生病了，所以今天没来公司。您有什么事情可以和我说，等她来了，我再告诉她。
★刘小姐今天身体不太好。
✅ 对
生病 = «заболела» → 身体不太好.
生病 и 身体不太好 — синонимичны в этом контексте.
爸爸明天早上9点下飞机，我们7点从家去机场就可以。
★他们明天早上去机场。
✅ 对
7 утра → это «早上».
早上 = с 5-6 утра до ~9-10 утра.
8 Соедините подходящие по смыслу реплики.
A. 对不起，请等一下，大卫还没到。
B. 你是这里的服务员吗？
C. 晚上去看电影？
D. 希望这次你能在这儿多住几天。
E. 好，没关系，我们再去别的商店看看。
1. 我是新来的，所以您可能没见过我。 → B
2. 怎么样？现在可以开始了吗？ → A
3. 明天要考试，考完试再去吧。 → C
4. 这是我第二次来北京。 → D
5. 这件衣服的颜色，我不喜欢。 → E
✅ Разбор:
1–B: «Я новенький» → ответ-вопрос «вы здесь официант?» (уточнение статуса).
2–A: «Начинаем?» → «Подождите, Дэвид ещё не пришёл».
3–C: «После экзамена пойдём» → про кино (C — именно про кино).
4–D: «Я второй раз в Пекине» → «Надеюсь, поживёшь подольше».
5–E: «Цвет не нравится» → «Ничего, пойдём в другой магазин».
Логика диалога: смотри не на отдельные слова, а на смысл ответа.
9 Подберите подходящие картинки к утверждениям.
A 🍉 арбуз · B 💼 бизнесмен с чемоданом · C 👨‍🍳 повар · D 🙍‍♀️ женщина хватается за голову · E 👫 пара стирает бельё
🍉A · Арбуз
💼B · Бизнесмен с чемоданом
👨‍🍳C · Повар
🙍‍♀️D · Женщина в стрессе
👫E · Пара со стиркой
1. 喂，我已经下飞机了，现在正往家里走呢。 → B
2. 丈夫帮助她一起洗衣服。 → E
3. 你别说了，我不想听，不想听。 → D
4. 西瓜是我最爱吃的水果。 → A
5. 她在饭店工作，她做的菜很好吃。 → C
✅ Совпадения:
1–B: «Я вышел из самолёта, иду домой» → бизнесмен с чемоданом.
2–E: 洗衣服 = «стирать» → пара у стиральной машины.
3–D: «Не говори, не хочу слушать» → женщина в стрессе, закрывает уши.
4–A: 西瓜 = «арбуз».
5–C: работает в ресторане + готовит → повар.
АУДИРОВАНИЕ
10 Прослушайте аудиозапись и ответьте на вопросы.
Скрипт (можно прочитать перед ответом): «妈妈在图书馆工作。她每天早上六点起床，起床后给我和爸爸做早饭，然后我们一起吃。七点半，她会先送我去学校，然后再去工作。图书馆九点开门，她常常差一刻九点到图书馆门口。中午妈妈会在图书馆的食堂吃饭。晚上我们一起在家吃晚饭，有时候一起看电视。这是我妈妈的一天。»
1. 她每天早上几点起床？
✅ A · 六点
«每天早上六点起床» — прямо в скрипте.
2. 起床后她做什么？
✅ B · 做早饭
После подъёма — сразу 做早饭. Школа — в 7:30.
3. 妈妈在哪儿工作？
✅ C · 图书馆
«妈妈在图书馆工作» — первое предложение скрипта.
4. «我»是谁？
✅ C · 女儿
«送我去学校» — значит, говорящий ребёнок, дочка.
5. 图书馆几点开门？
✅ A · 九点
«图书馆九点开门» — прямая цитата.
差一刻九点 = «без четверти девять» — она приходит раньше открытия.
6. 他们在哪儿吃晚饭？
✅ A · 家里
«晚上我们一起在家吃晚饭» — дома. В食堂 она ест только в обед.
Можно ещё проверить: 在家吃 / 在外面吃 / 在食堂吃 — три варианта.
